# AGENTS.md

Minecraft の Paper サーバー用プラグインのプロジェクトです。開発には、AI エージェント用のスキル `paper-developer` を使います。

- **作業を始める前に、ルートの `PLUGIN.md` を読むこと。** 何をするプラグインか、対象のサーバーと Java、コマンドと権限、設定、決まりなど、このプラグインに固有の情報はそこにある。`PLUGIN.md` が無いときや、先頭に `<!-- paper-developer:plugin-template -->` が残っている（まだ書かれていない）ときは、コードを読んで下書きすることを作者に提案する。
- `paper-developer` スキルが使えるときは、その `SKILL.md` に従う。コードを変えたら、スキルのスクリプトで確かめる。
- スキルが入っていないときは、導入を作者に提案する。入れるのは作者の確認を取ってから。導入の手順は https://github.com/ukagaka-irono/paper-developer にある。
- このプラグインだけの決まりは `PLUGIN.md` に書く。
